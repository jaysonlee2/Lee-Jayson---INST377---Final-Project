# Pokémon Black and White Unova Starter Finder

## Description
Pokémon Black and White Unova Starter Finder is a web application that helps players choose between the three starter Pokémon from Pokémon Black and White: Oshawott, Tepig, and Snivy. The application uses PokéAPI data, user-selected stat sliders, and playstyle questions in order to generate a personalized starter recommendation. Users can also compare starter stats visually, save their choices using Supabase, and view previous saved recommendations.

## Target Browsers
This application is designed for modern desktop and mobile browsers who want help choosing their starter.


### Desktop Browsers
- Google Chrome
- Safari

### Mobile Browsers
- Google Chrome on iOS/Android
- Safari on iOS
