# Developer Manual

## Project Overview
Unova Starter Finder is a Node.js web application that helps users choose between Oshawott, Tepig, and Snivy from Pokémon Black and White. The app uses PokéAPI for Pokémon data, Supabase for saving starter choices, and a frontend built with HTML, CSS, JavaScript, and Chart.js.

-------------------------------------------
# How to Install the Application

# 1. Clone the GitHub Repository

```bash
git clone https://github.com/jaysonlee2/Lee-Jayson---INST377---Final-Project.git

# 2. Move into the project Folder
cd Lee-Jayson---INST377---Final-Project
 
# 3. Install Dependencies
npm install

# 4. Create Environment Variables
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_publishable_key

# 5. Run the application
npm start
# Then the application should run at "http://localhost:3000"
